# 内容源边界

> 项目定位：只做本地文件 + 用户自己的网盘，不内置在线书源（2026-09-12 确认）

雨读 Yudu 是**本地漫画阅读器**，内容来源只有两类：

- 本地目录与压缩包（cbz/cbr/cb7/cbt/pdf 等）；
- 用户自己的网盘（天翼云盘、115 网盘、WebDAV/NAS）。

明确不做：

- 不内置任何在线漫画书源，不提供盗版站抓取、反爬绕过或 DRM 破解能力；
- 不替用户判断内容版权，工具只负责读取用户已有的文件。

将来若扩展在线能力，只考虑合规方向：OPDS 目录订阅、正版平台开放接口、公有领域源（如 Digital Comic Museum、Comic Book Plus）。日本 NDL デジタルコレクション的旧 opensearch API 已返回 405，需重新摸接口。
