# B站漫画阅读器模式

> B站漫画网页版阅读器实测的 UX/架构模式清单，供 Yiben 阅读器功能借鉴

2026-09-10 实测 manga.bilibili.com 阅读器（页式柯南 + 竖条漫两部作品）得出的可借鉴模式：

- 跨页体系：指示器 "N | M" 显示当前跨页两页页码；"2 / 21" 按 spread 计数（41P→21 spread，封面保持单独）；「更改跨页匹配(C)」一键切换奇偶配对偏移并立即重排；配 Toast 提示「跨页内容不匹配可点此修正」。对 雨读 Yudu 双页末屏判定：与其纯自动判定，不如提供手动修配对。
- 翻页方向：日漫 RTL 有一次性提示浮层「当前阅读器翻页方向 从右向左」；点击区方向感知（RTL 点左侧=前进）；点击只翻页不跨话，跨话仅在末页继续翻时发生。
- 键盘：空格=下一页、退格=上一页、方向键/PgUp/PgDn=翻页、C=跨页匹配、回车=唤出工具栏；帮助面板画成可视化键盘图。
- 进度：刷新后精确恢复到原 spread（未登录也生效）；URL 只含话 id，页级进度另行存储。
- 跨话：末页继续翻（空格）SPA 无缝进下一话；slider 右端按钮语义=下一话，左端=回本话开头。
- 渲染：正文全 canvas（页式每页一个 canvas；条漫约 12 个 canvas 分段虚拟化窗口），配 WASM 解扰（DRM）；不用 img 标签。条漫分段虚拟化值得 Yiben 的云端长图阅读参考（内存控制）。
- 其他：阅读模式可用性感知内容格式（竖条漫章節禁用「左右翻页」按钮）；工具栏自动隐藏；图片降噪开关；单话评论计数显示在工具栏；目录为浮动面板当前话高亮；章节末页含版权页/推广卡。

**Why:** 这些是实测验证过的成熟阅读器交互，Yiben 后续做阅读器迭代时可直接对照取用。
**How to apply:** 优先落地：跨页手动重配对（C 键）、RTL 方向提示浮层、键盘帮助键盘图、末页无缝跨话、刷新位置恢复。——以上五项已于 2026-09-10 全部实现并验证（spreadOffset 偏移存 readerPrefs 按系列记忆；C 键 + 顶栏按钮；帮助为居中键盘图模态 KeyboardHelp.tsx；反向跨话经 ?p= 深链落上一话末页；pagehide 补写进度）。未落地：canvas 分段虚拟化（条漫内存优化）、评论/弹幕类社区功能。
