# 雨读交互复查与外观优化

日期：2026-10-11；基于 v0.2.2 当前工作区。此前可靠性审查见 `PROJECT_AUDIT_2026-10-10.md`。本轮查看了实际 Electron 窗口，并复查设置、阅读器、系列管理与云盘导航，修复如下问题。

## 修复与优化

| 场景 | 原行为 | 当前行为 |
| --- | --- | --- |
| 主题选择 | 三段色块难以预判界面效果；顶栏只能盲轮换 | 三套独立配色的书架预览；名称、明暗标签、对勾和边框明确选中项；顶栏直接选择，支持方向键、Esc 与焦点返回 |
| 主题配置损坏 | 未知主题可导致轮换到 undefined | 读取与写入校验，恢复为纸墨主题，保留旧版迁移 |
| 阅读设置 | 系统蓝色滑块与主题不一致，连续设置依赖异步回写 | 护眼 / 增强分组、主题色开关与滑块、百分比 / 倍率；操作立即反馈，保存错误可见，旧回复不覆盖新选择 |
| 长设置页 | 备份、诊断与更新需要长距离滚动查找 | 顶部固定分区入口，跳转后标题避开导航 |
| 书架与标签 | 快速连续操作基于旧数组，全量写入可能丢修改 | 顺序提交功能型变更，下一次基于已保存结果；失败不污染后续基准 |
| 重置进度与元数据保存 | 一次误点直接清空；保存中能关闭再重开弹窗 | 重置先确认，取消保留进度；元数据保存中禁止关闭 |
| 云盘目录 / 家庭空间 | 请求前修改路径，失败后旧列表和新挂载路径不一致 | 成功后同时提交空间、路径与内容；失败保持原归属，旧请求不能覆盖新请求；未加载目录不能挂载 |
| 二维码登录错误 | 首次取码失败仍转圈，只能关闭重开；轮询错误静默 | 取码失败结束加载并提供重新获取；连续轮询失败显示重试提示，成功后清错并保留扫码状态；刷新 / 关闭后旧响应失效 |
| PDF 键盘与控制项 | 键盘只修改页码，没有滚动画面；模式 / 旋转按钮无效 | 键盘跳页同步视口；明确显示连续阅读并隐藏无效图像控制 |
| 条漫跨话 | 回退重复加偏移，缩略图 / 标题 / 模式切换可能指向旧话 | 使用当前话局部页码，回到上一话用绝对位置；界面跟随视口归属；离开条漫时转到当前话与当前页 |
| 阅读器按钮与键盘 | 前后话落在窗口拖拽区；按钮空格 / 回车被阅读快捷键抢走 | 排除拖拽；保留控件原生激活键与修饰键行为 |
| 弹窗 | 无焦点约束和恢复；滑块聚焦后 Esc 失效 | 模态语义、初始焦点、Tab 双向循环、嵌套恢复；Esc 可关闭并返回入口，忙碌时锁定关闭；长内容限高滚动 |
| 缓存清理 / 备份恢复 | 原生阻塞确认框不随主题，缺少对象明细 | 共用主题确认框；缓存展示范围、大小、文件数与离线影响，恢复展示备份时间、大小、类型及重启 / 安全快照说明；默认聚焦取消，执行中同步锁定，失败留在框内可重试 |
| 清理后的焦点 / 长标题 | 成功后入口删除或禁用，焦点落到页面主体；连续英文长标题可能溢出 | 原入口可用则恢复，否则落到云端缓存标题；说明与详情允许任意长词换行，详情值列使用可收缩布局 |
| 系列详情信息层级 | 顶部混合阅读、信息与维护动作 | 首屏作品卡突出封面、标题、作者、状态、进度和主阅读入口；章节列表为主内容，作品信息 / 书架标签与系列管理分区；宽窗口并排，最小窗口纵向排列 |
| 系列继续阅读 / 章节键盘 | 只读部分章节仍显示开始阅读，跳话后入口回到首个未读话；勾选按钮回车冒泡打开章节 | 有保存进度即显示继续阅读，优先最近未完话，与首页的时间并列规则一致；章节行只响应自身回车 / 空格，勾选按钮保留独立动作 |
| Windows 窗口尺寸恢复 | 150% 缩放下保存外框尺寸后重建，每次重开约增加 4 像素 | 使用当前正常外框 / 内容区差值恢复内容尺寸，最大化前校正；保留既有配置格式、坐标与最大化状态 |
| 空态与格式标识 | 不存在的系列永久加载；阅读失败无鼠标返回；正常 PDF 被标成扫描失败；WebDAV 被称为本地 | 系列与章节提供明确返回入口；PDF 排除扫描能力边界提示；WebDAV 正确标识 |

## 验证方法

- 单元测试覆盖损坏主题配置、异步连续提交 / 失败恢复 / 目录旧响应、弹窗焦点栈和阅读键盘语义。
- `pnpm test:reader` 使用新建临时书库和独立 `--user-data-dir`。主题、保存行为、PDF 键盘画面、条漫跨话 / 模式切换、弹窗 Tab / Esc、连续书架 / 标签操作、重置取消 / 确认均读取实际 DOM 或持久化结果。
- 同一脚本保存浅色设置截图和两套深色主题的最小窗口截图（名义尺寸 960×640，Windows 缩放下实际内框有少量舍入差异），检查卡片宽度及可视边界。无真实用户书库写入。
- 缓存回归在临时 profile 中创建两个明确归属的文件，共 10 KB，验证取消、单系列 / 全部真实清理、长标题换行、成功后的焦点和完整进度保持；恢复只验证选中信息与取消，确认未产生 `pending-restore.sqlite`。数据库恢复流程另有主进程单测覆盖。
- 系列回归分别验证三主题的最小窗口和漫画主题的宽窗口、首屏阅读入口、章节 / 信息 / 管理层级、跳话继续提示、各维护弹窗打开与取消；保存截图后逐张检查。测试没有确认移出或回写漫画文件。
- 窗口恢复先用独立 Electron 实验验证不同坐标、奇数尺寸、最小尺寸和最大化场景各连续 5 次重开，再在实际应用中连续 3 次关闭 / 重开，读取 DOM 与数据库保存尺寸，确认均保持 960×641 内容区、962×641 外框，没有逐次累积。

本轮结果：`pnpm typecheck`、`pnpm test`（40 个文件 / 247 个用例）、`pnpm build` 均通过；`pnpm test:reader` 的全部标记通过，包括新增 `CONFIRMATION_DOM_OK`、四次 `SERIES_LAYOUT_OK` 与 `WINDOW_RESTORE_OK`。相比首轮 205 个用例新增 42 个单测，涵盖主题、提交竞态、阅读键盘、弹窗焦点、确认操作、系列继续阅读、窗口恢复及二维码错误恢复。
